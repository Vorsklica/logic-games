Де взяти ще задачі

Є ще кілька цікавих варіантів.

1. Shadify — генератор задач

Це, мабуть, найзручніший варіант для нас. Сервіс має генератор випадкових Tents & Trees, причому можна задавати розмір від 5×5 до 15×15, а API може повертати і саме завдання, і розв'язок.

Shadify — Camp / Tents and Trees

Тобто це вже потенційно дуже зручне джерело для нашого data.js.

2. GitHub tournageCoding/TentsAndTreesSolver

Цікавий тим, що в репозиторії є папка testFiles з готовими задачами. Автор використовує пошук у глибину (depth-first search) для розв'язання.

GitHub — TentsAndTreesSolver

Тут я б особливо подивився саме testFiles — можливо, звідти ми зможемо взяти кілька задач для тестування нашої гри.

3. disposedtrolley/tents-and-trees

Цікавий проект тим, що це не тільки solver, а generator and solver. Тобто автор саме генерує нові поля.

GitHub — tents-and-trees generator and solver

4. ghewgill/puzzles

А це взагалі дуже цікавий варіант. Там є реалізація Tents у великій збірці логічних головоломок. Причому автор окремо розбирає саме ту тонкість, з якою ми сьогодні мучилися: відповідність tree ↔ tent фактично є задачею про perfect matching. Він прямо зазначає, що при перевірці розв'язку достатньо існування хоча б одного такого matching.

GitHub — Simon Tatham's Portable Puzzle Collection, tents.c

Що я пропоную для нашої гри

Я б не поспішав брати задачі навмання. Можемо зробити набагато цікавіше:

взяти 5–10 готових задач із цих репозиторіїв, перетворити їх у наш формат data.js і прогнати через нашу checkGame().

Це дасть нам дуже хороший тест нашої сьогоднішньої рекурсивної checkTrees() — особливо задач із розгалуженнями та «хитрими» перетинами.
