## Налаштування Live Server

Після реалізації збереження чернеток редактор перезавантажував сторінку при записі файлів у папку `editor/drafts`. Причина — Live Server відстежував зміни у файлах проєкту.

Для усунення проблеми:

1. У корені проєкту створити папку `.vscode` (якщо її ще немає).
2. Створити файл `.vscode/settings.json`.
3. Додати до нього:

```json
{
  "liveServer.settings.ignoreFiles": [
    "**/.vscode/**",
    "**/.git/**",
    "**/node_modules/**",
    "**/editor/drafts/**",
    "**/editor/accepted/**"
  ]
}

4. Перезапустити Live Server.

Після цього збереження файлів у папках drafts та accepted більше не викликає автоматичного перезавантаження сторінки.
```

Шпаргалка: відновлення видаленої папки через Git

1. Якщо видалення ще НЕ закомічене:

git restore шлях/до/папки

2. Якщо видалення ВЖЕ закомічене:

Подивитися історію:

git log --oneline

Якщо термінал «завис» — натиснути q.

Знайти commit, у якому папка ще існувала, і виконати:

git restore --source=ID_КОМІТУ -- шлях/до/папки

Наприклад:

git restore --source=db3ad9e -- games/03-input/content/data-002

3. Перевірити результат:

git status

4. Якщо все добре — зберегти відновлення:

git add шлях/до/папки
git commit -m "Відновлено папку"
git push
